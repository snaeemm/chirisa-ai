# Chirisa AI - Data Center Site Analysis

AI-powered data center site suitability analysis platform using Google ADK and Gemini 2.5.

## Features

- Multi-agent architecture with 7 specialized analysis agents
- Real-time API data integration (WRI Aqueduct, ThinkHazard, PeeringDB, OSM)
- Investment-grade reports with source verification
- Interactive Streamlit interface
